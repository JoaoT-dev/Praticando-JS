# Praticando JS

Este repositório foi criado para praticar e reforçar os conceitos de JavaScript por meio de exercícios, desafios e pequenos projetos. O objetivo é desenvolver a lógica de programação, entender a sintaxe da linguagem e melhorar a capacidade de resolver problemas com código.

## Objetivo

- Aprender os fundamentos do JavaScript;
- Praticar lógica de programação;
- Explorar conceitos como variáveis, funções, arrays, objetos e eventos;
- Desenvolver pequenos projetos para consolidar o conhecimento;
- Evoluir gradualmente do nível básico ao intermediário.

## Tecnologias e conceitos abordados

- JavaScript puro;
- HTML e CSS para interações com a página;
- Manipulação do DOM;
- Funções e escopo;
- Condicionais e laços de repetição;
- Arrays e objetos;
- Eventos e programação dinâmica;
- Exercícios de lógica e mini projetos.

## Como usar este projeto

1. Clone o repositório para sua máquina:
2. Acesse a pasta do projeto:

## Dicas de estudo

- Pratique diariamente por alguns minutos;
- Tente resolver os exercícios antes de olhar a solução;
- Reescreva o código para entender melhor o funcionamento;
- Teste diferentes entradas para verificar o comportamento;
- Construa mini projetos para aplicar o que foi aprendido.
